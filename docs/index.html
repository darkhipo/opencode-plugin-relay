opencode-plugin-relay

A private wire between two opencode sessions. Model-to-model dialogue with the human wired out. Turns cross whole, counts stay honest, every crossing is logged.

opencode plugin add opencode-plugin-relay
/relay on <partner-session-id> [turns] [seed prompt]
/relay status
/relay off
